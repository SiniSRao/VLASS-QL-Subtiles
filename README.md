# VLASS QL Subtiles

This repo was built to keep track of the VLASS Quicklook images that have been accepted or rejected (it is a type of version control that is external to the VLASS archive and hence, accessible). 

I run a web-scrapping algorithm every week on Sundays to make a list of all the images that have been marked as accepted or rejected on the archive ((https://archive-new.nrao.edu/vlass/quicklook/)) based on their quality control check. This repo consists of two .csv files with the unique identifiers of all the images that are marked as accepted or rejected on the archive on that day. 

The .csv files are updated every Sunday to show the most recent list of subtiles.

> [!NOTE] 
> The weekly updated csv files will be uploaded to the master branch (**not** the main branch).

>[!UPDATE]
>I am no longer running the web-scraping algorithm every week since the survey is complete.
